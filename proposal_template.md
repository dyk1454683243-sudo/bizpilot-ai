## 🔒 3. Safe Client Disclosures & Transparency

Maintain absolute clarity during sales pitches to establish trust:

### Razorpay Test Mode Disclaimer
> *"Currently, the payment gateway on the BizPilot AI demo operates in **Test Mode**. It simulates credit card and UPI payments to demonstrate invoicing flows. To collect real money from customers, we will set up a merchant account in your business's name with Razorpay, complete the required KYC registration, and link your live production keys. All client payments will then go directly into your official bank account."*

### Template-Based Follow-Ups Explanation
> *"The follow-up message generator uses pre-configured operational copy templates. It drafts localized messages tailored to your customers (in English or Hinglish) ready for you to share via WhatsApp or SMS. It does not communicate with external paid AI platforms like OpenAI, which means you will never receive unexpected monthly AI API usage bills."*

### Demo-Ready vs Production-Ready
* **Production-Ready**: The user authentication flow, database security models (Row-Level Security), relational integrity (leads linked to invoices/appointments), and API checkouts are fully complete and secure.
* **Demo-Ready**: The system is currently configured on sandbox test credentials. Transitioning to production only requires replacing keys in the server configuration file (`.env.local`).

## ⚙️ 4. Onboarding Customization Matrix

During onboarding, compile these details from the client to customize their deployment:

1. **Branding Identity**: Business Name, Brand Colors, and Logo files.
2. **Operations Menu**: Service categories, descriptions, and list prices.
3. **Staff Profiles**: Names, roles, and scheduled shifts.
4. **Working Hours**: Standard weekly opening/closing times.
5. **Contact Config**: Public support phone number, WhatsApp contact link, and physical office addresses.
6. **Payment Credentials**: Razorpay Merchant Keys (or standard UPI IDs for QR generation).
